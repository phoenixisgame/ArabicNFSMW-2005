## 🇬🇧 English Description

Hey everyone! 🏎️💨

I'm excited to announce that **Version 1.2** of my Arabic localization mod for **Need for Speed: Most Wanted (2005)** is complete!

### 🔥 What's new in v1.2?
* 🇩🇿 **Arabic language selection at startup:** Arabic is now available directly in the game's language selection screen.
* 💬 **Extensive Arabic localization:** Covering menus, SMS messages, notifications, and other in-game text, aiming for a complete Arabic experience.
* 📩 **SMS & Notifications:** Bringing Arabic to more than just the main menus.
* 🛠️ **Compatibility with different game versions:** Designed and tested to work smoothly across multiple versions of the game.
* 😂 **A funny surprise!** The Blacklist rival racers now have hilarious Arabic names and aliases! I'll leave the surprise for you to discover in-game! 😆

The goal is to make this legendary racing game more accessible and enjoyable for Arabic-speaking players while preserving its original spirit and nostalgia.

* **Game:** Need for Speed: Most Wanted (2005)
* **Version:** Arabic Localization v1.2
* **Creator:** phoenixisgame

Copy it into the NFSMW\scripts folder. I haven't tested it with modified versions. Enjoy!

 Hey everyone!

I'm excited to announce that version 1.2 of my Arabic localization mod for Need for Speed: Most Wanted (2005) is complete!
🔥 What's new in v1.2?

    🇩🇿 Arabic language selection at startup — Arabic is now available directly in the game's language selection screen.

    💬 Extensive Arabic localization — covering menus, SMS messages, notifications, and other in-game text, aiming for a complete Arabic experience.

    📩 SMS and notifications — bringing Arabic to more than just the main menus.

    🛠️ Compatibility with different game versions — designed to work across multiple versions of the game.

    😂 A funny surprise! The rival racers now have Arabic names, including some unexpected and hilarious choices. I'll leave the surprise for you to discover in-game!

The goal is to make this legendary racing game more accessible to Arabic-speaking players while preserving its original spirit.
